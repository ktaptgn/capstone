# 05_CAPSTONE_BENCHMARK_CASES.md

## C5.1 Benchmarking Position

C5.1 should be evaluated as a capstone project by three things:

1. Does the team define a clear operating decision problem?
2. Does the simulation actually run and produce interpretable logs?
3. Are policy comparisons made under fair and identical conditions?

---

## Strong Capstone Pattern

| Element | C5.1 Response |
|---|---|
| Clear problem | Truck operating schedule with PM under demand constraint |
| Working artifact | Simulation visualization MVP |
| Engineering method | H0-H4 heuristic comparison |
| Quantitative output | KPI summary and policy report |
| Practical interpretation | PM cost, demand fulfillment, available trucks, downtime |

---

## Portfolio Expansion

After C5.1 core is stable, the project can expand into:

- operator dashboard
- PM Android app
- dashboard-app work order interaction
- optional RL comparison

These are not current C5.1 implementation tasks.
