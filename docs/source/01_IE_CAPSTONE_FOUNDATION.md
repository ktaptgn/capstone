## C5.1 Industrial Engineering Positioning

C5.1 is not a graphics project and not an RL-first project.

It is an industrial engineering scheduling problem:

> Equipment availability, preventive maintenance timing, operating demand, bottleneck resources, and operating cost are considered together to compare scheduling policies.

---

## IE Keywords

| Keyword | C5.1 Meaning |
|---|---|
| Dispatching | Which truck should go to which work destination |
| Preventive Maintenance Scheduling | Which truck should enter PM and when |
| Resource-Constrained Scheduling | Truck count, PM bay capacity, crusher capacity, and time are limited |
| Discrete Event Simulation | Truck operation progresses through events and states |
| Heuristic Baseline | Rule-based policies used for comparison |
| Cost-Based Decision | PM, downtime, unmet demand, and degradation are represented as costs |

---

## Core Academic Value

C5.1 shows that the team can:

1. Define an operating decision problem.
2. Simplify a real industrial system into a controllable simulation.
3. Design comparable baseline policies.
4. Evaluate policies with interpretable KPIs.
5. Connect simulation results to visualization and later decision-support interfaces.

---

## Presentation Positioning

Use this sentence when explaining the project:

> The mine is the case environment. The actual industrial engineering problem is a resource-constrained scheduling problem involving truck availability, PM timing, demand fulfillment, and operating cost.
