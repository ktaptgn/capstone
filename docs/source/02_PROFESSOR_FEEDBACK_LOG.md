## Purpose

This document records professor feedback as design constraints for C5.1.

## Week 10 Feedback Summary

### Main Diagnosis

- The topic itself is valid.
- The team must explain the problem in its own words.
- The project should not start from RL.
- Simulation visualization and heuristic baseline should come first.
- The project should be framed as a mine truck transport simulation with PM scheduling.

### Feedback-Based Structure

| Item | C5.1 Decision |
|---|---|
| Model | Mine truck transport simulation |
| Decision | Truck operating schedule |
| Objective | PM cost minimization and operating loss reduction |
| Constraint | Given demand satisfaction |
| First implementation | Simulation visualization |
| First algorithm | Heuristic baseline |
| Later extension | RL comparison |

---

## Week 11 Mid-Presentation Comment Summary

- The project should be positioned as an industrial engineering scheduling and PM problem.
- The presentation should show a clear operating problem, not an AI slogan.
- Extreme operating conditions and frequent PM events make the setting meaningful.
- A working simulation and explainable comparison are more important than claiming RL superiority.
