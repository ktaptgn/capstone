# C5.3 Dispatch-Only Results: H0-H4 (recast) under shared rule-based PM

- Environment: 25-truck C5 mine + C6 routes A/B/C; 3-component HI (tire/engine/brake), frailty (Gamma wear heterogeneity) and C6 sensor noise. Decision target = DISPATCH only; PM delegated to a FIXED CBM rule engine (H*=0.21/0.21/0.28) shared byte-identically by every policy. Objective = total TCO (pm+cm+downtime+degradation+unmet).
- Policies (route-selection recast of the C5.2 heuristics): H0 route-blind baseline, H1 health routing, H2 risk-aware routing, H3 value (grade) routing, H4 capacity routing.
- In-lab benchmark; not an official C5.1 ranking.
